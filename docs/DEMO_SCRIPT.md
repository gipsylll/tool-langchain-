# Демонстрация

1. Запустить `run.command` или команду из README. Открыть локальное приложение на порту 8502.
2. Показать раздел «Данные»: 22 831 синтетическая строка, схема и пропуски.
3. Выбрать «Через ChatGPT / Codex», задать: «Рассчитай средний чек по регионам и построй график». Нажать «Запустить Codex»: обработка начинается автоматически. Показать этап и таймер. В настройках можно включить прежний ручной режим через чат. Показать готовую таблицу, график по её result_id и журнал.
4. Сменить режим на Gemini API, в настройках ввести ключ и проверить Tool Calling. Задать вопрос про изменение выручки сентября и октября.
5. Открыть шаги анализа. Показать, что Gemini сам выбирал инструменты и использовал реальные вычисления.
6. Скачать ZIP-отчёт с ответом, таблицами, графиками и журналом.

Без Gemini-ключа демонстрируется первый режим через текущего ассистента. Программный обзор не выдаётся за действия модели.

Проверочные значения: `python scripts/verify_demo.py`.
