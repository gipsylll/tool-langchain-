# AI Data Analyst · локальное приложение

Два режима работы с общими локальными данными, вычислениями и результатами. Модели на компьютере не запускаются и не скачиваются.

| Режим | Как работает | Что требуется |
|---|---|---|
| ChatGPT / Codex | Кнопка сразу запускает облачный Codex CLI: модель возвращает план расчёта, приложение выполняет его локально и публикует результат. | Установленный Codex CLI и вход через ChatGPT (`codex login`); отдельного API-ключа приложения нет. |
| Gemini API | Приложение запускает LangGraph-агента: Gemini выбирает инструменты, получает результаты и публикует ответ. | Ключ Google и доступная ему Gemini-модель с Tool Calling. |

Codex CLI запускает отдельную облачную сессию через уже выполненный вход ChatGPT. Приложение не посылает сообщения в текущий чат. Ручная обработка из чата через локальные инструменты и MCP остаётся отдельной настройкой.

## Запуск

Нужны Python 3.11+ и uv.

```bash
uv sync
uv run streamlit run app.py --server.address 127.0.0.1 --server.port 8502
```

Открыть http://127.0.0.1:8502. На macOS можно дважды нажать `run.command`.
Демонстрационные синтетические продажи загружаются автоматически. Можно загрузить свой CSV / XLSX и переключаться между сохранёнными таблицами.

## Через ChatGPT / Codex

1. Выберите «Через ChatGPT / Codex».
2. Введите вопрос и нажмите «Запустить Codex». Сообщение в этот чат больше не требуется.
3. Обработка сразу запускается в фоне. Карточка показывает этап, модель / глубину и таймер, обновляясь раз в секунду.
4. Модель одним вызовом готовит JSON-план с Python-кодом; приложение выполняет расчёт в worker и строит график по итоговой таблице. Числа ответа берутся из результата worker. Для сложного многошагового анализа используйте Gemini или ручную обработку через этот чат.

В «Настройках» можно выбрать модель и глубину `low / medium / high`. По умолчанию — **Luna 6 (`gpt-6-luna`) и `low`**. Пустое имя возвращает Luna 6; короткое `luna` сопоставляется с доступным полным ID из локального кэша CLI. `low` уменьшает глубину рассуждений, но время ответа зависит также от сервиса и сети.

Локальная модель не запускается. CLI получает схему, небольшой пример и вопрос; исходный файл целиком не отправляется. CLI запускается в режиме read-only и возвращает план, вычисления выполняет приложение. Глобальная конфигурация CLI не загружается; авторизация сохраняется. На один ответ модели установлен timeout 90 секунд, до двух запросов одновременно. Ошибки запуска и сети завершают запрос явным сообщением. События CLI читаются сразу: интерфейс различает подключение, ожидание и получение плана. Сетевые повторы ограничены одним, простой потока — 30 секундами. Готовый структурированный ответ забирается сразу, без ожидания выхода CLI; зависшие дочерние процессы завершаются. У неудачного запроса есть кнопка «Повторить Codex». В журнал не попадают сырые сообщения CLI, ключи и скрытые рассуждения.

Если нужен прежний ручной режим, включите «Обрабатывать вручную через этот чат», сохраните вопрос и отправьте ассистенту фразу из его карточки.

Локальные команды из каталога проекта:

```bash
uv run python -m data_analyst.cli pending
uv run python -m data_analyst.cli inspect RUN_ID
uv run python -m data_analyst.cli execute RUN_ID --code-file analysis.py
uv run python -m data_analyst.cli chart RUN_ID RESULT_ID region average --title 'Средний чек по регионам'
uv run python -m data_analyst.cli finish RUN_ID --answer-file answer.md --result-ids RESULT_ID
uv run python -m data_analyst.cli show RUN_ID
uv run python -m data_analyst.cli export RUN_ID report.zip
```

`RUN_ID` и `RESULT_ID` заменяются идентификаторами, возвращёнными инструментами. Для повторного использования текущих зависимостей без синхронизации можно выполнить `.venv/bin/python -m data_analyst.cli` с теми же аргументами.

Код `analysis.py` для среднего чека по регионам:

```python
result = (
    df.groupby("region")
    .agg(
        revenue=("revenue", "sum"),
        orders=("order_id", "nunique"),
    )
    .reset_index()
)
result["average"] = result["revenue"] / result["orders"]
```

`df`, `pd`, `np` уже доступны. Импорт не нужен. Итог присваивается переменной `result`. Таблица и график используют один `result_id`, без повторной агрегации. Значения в тексте всё равно должен проверить ассистент: наличие ссылки на результат само по себе не доказывает истинность каждой фразы.

## MCP

Сервер stdio запускается как `uv run python -m data_analyst.mcp_server`. У него нет собственной модели или облачных ключей. Он предоставляет `list_sessions`, `pending_requests`, `inspect_data`, `execute_python`, `create_chart`, `publish_answer`.

Пример для клиента с JSON-конфигурацией MCP:

```json
{
  "mcpServers": {
    "local-analyst": {
      "command": "/ABSOLUTE/PATH/ai-data-analyst/.venv/bin/python",
      "args": ["-m", "data_analyst.mcp_server"],
      "env": {
        "ANALYST_DATA_DIR": "/ABSOLUTE/PATH/ai-data-analyst/.local-data",
        "PYTHONPATH": "/ABSOLUTE/PATH/ai-data-analyst"
      }
    }
  }
}
```

Для Codex с TOML-конфигурацией:

```toml
[mcp_servers.local_analyst]
command = "/ABSOLUTE/PATH/ai-data-analyst/.venv/bin/python"
args = ["-m", "data_analyst.mcp_server"]

[mcp_servers.local_analyst.env]
ANALYST_DATA_DIR = "/ABSOLUTE/PATH/ai-data-analyst/.local-data"
```

Используйте фактический абсолютный путь. Файлы конфигурации клиента автоматически не меняются. UI, CLI и MCP должны указывать на одну папку данных.

## Gemini API

1. Выберите «Gemini API» → «Настройки».
2. Введите API-ключ Google и имя модели, доступной вашему ключу. Предзаполненное имя можно изменить.
3. Нажмите «Применить и проверить Tool Calling» — это реальный короткий запрос к API.
4. Вернитесь в «Анализ», задайте вопрос и запустите Gemini.

Можно использовать переменные из `.env.example`, скопировав файл в `.env`. Ключ не сохраняется в SQLite, журнал и отчёт. Ключ в UI хранится только в памяти браузерной сессии Streamlit. Если указать ключ в `.env`, этот файл остаётся на вашем компьютере и исключён из git и поставки.

Используется официальный OpenAI-compatible endpoint Gemini:
https://generativelanguage.googleapis.com/v1beta/openai/

Модели передаются вопрос, схема, примеры строк и результаты вычислений, а не исходный файл целиком. Результаты могут содержать данные таблицы. Ошибки доступа, квоты, неизвестной модели и сети показываются отдельно. SDK-исключения с HTTP-деталями в историю не пишутся.

## Что сохраняется

Локальная папка `.local-data` содержит SQLite с вопросами, статусами, журналом и результатами, а также неизменяемые Arrow-копии загруженных таблиц. Они сохраняются после перезапуска. В экспорт входят Markdown-ответ, CSV-таблицы, автономные HTML-графики и журнал инструментов. Экспорт подготавливается по кнопке.

Разделы: «Анализ», «Обзор», «Данные», «Настройки». Обзор прямо обозначен как программные вычисления. История и результаты отделены по таблицам и запросам; результаты чужого запроса нельзя использовать в своём ответе.

## Ограничения

- Учебный Python runner: отдельный процесс, AST-подмножество, CPU/time/output/result limits. **Это не промышленная песочница для враждебного Python-кода.** Жёсткого лимита RSS нет.
- До 30 MiB, 200 000 строк и 80 колонок; первый лист XLSX, распакованный XLSX до 150 MiB. Строковые ID сохраняются при передаче в worker. Даты распознаются только по явно названным колонкам.
- До 12 вычислительных вызовов на запрос. Бюджет Gemini 120 секунд проверяется между шагами; начатый HTTP-вызов ограничен своим timeout, поэтому общий предел не является жёстким.
- До 20 000 строк / 5 MiB на вычисленный результат; график до 5000 точек. Данные не обрезаются молча.
- Каждый вопрос анализируется самостоятельно; для уточнения включите нужный контекст в вопрос. История не передаётся в новый запрос автоматически.
- Нет автоматической установки MCP, многопользовательского доступа и автоматического удаления истории. Приложение слушает только loopback.
- Подключение к настоящему Gemini требует вашего ключа. Тесты используют модель и HTTP-ответы без платного внешнего вызова.

## Проверка

```bash
uv run pytest -q
uv run ruff check .
uv run ruff format --check .
uv run python scripts/verify_demo.py
```

Тесты проверяют реальные worker-процессы, сохранение и изоляцию результатов, общий бюджет между экземплярами, отказ публиковать ответ без вычислений, MCP stdio с настоящим SDK-клиентом и сквозной сценарий Streamlit.

Документация: [Gemini compatibility](https://ai.google.dev/gemini-api/docs/openai), [MCP Python SDK 1.x](https://py.sdk.modelcontextprotocol.io/v1/). SDK ограничен `mcp<2`, чтобы изменения протокола 2.x не меняли контракт клиента незаметно.
